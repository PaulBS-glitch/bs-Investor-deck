Appendix 5 / Illustrative economics and investor return profile

Show the economics at an illustrative, diligence-ready level.

This appendix can show contribution sizing, exit timing, property value sensitivity and portfolio-level return logic without turning the main deck into a financial model.

01

Contribution sizing

02

03

Return sensitivity

Tests property value, pricing multiplier, contribution percentage and portfolio performance sensitivity.

Positioning

Illustrative, not a return promise.

This appendix should support investor discussion by showing how returns may be generated and sensitivity tested, subject to pilot data, credit controls and final facility terms.

Appendix takeaway: economics should be transparent, sensitivity-tested and tied to actual contribution-layer portfolio performance.
