Appendix 4 / Exit risk and fallback pathways

Exit risk is managed through refinance-first discipline, scheduled review and fallback controls.

BuySooner is not designed as indefinite exposure. Each transaction needs a credible exit pathway before approval, with review points and alternative pathways if refinance becomes difficult.

01

Exit tested before approval

The transaction must show a credible refinance or sale pathway under conservative assumptions before BuySooner funds the contribution layer.

02

Refinance-first pathway

The preferred exit is customer refinance once senior debt, income capacity, valuation and BuySooner repayment can be supported.

03

Year 3 review

Scheduled review updates valuation, borrower position, senior debt balance and refinance capacity before the file approaches the policy endpoint.

04

Sale fallback

If refinance is not viable, sale remains the primary fallback because it converts the property value into repayment proceeds.

05

Final resolution pathway

Structured file management sits behind refinance, partial exit and sale pathways where a cooperative exit is not achieved.

Exit classification

Every review should produce a clear pathway.

The key control is not hoping the market grows. The control is classifying the exit position early and moving the file into the right pathway.

Pathway 1

Full refinance viable

Pathway 2

Partial exit viable

Pathway 3

Sale fallback required

Pathway 4

Final resolution

Control sequence

How downside is managed.

  1. Monitor borrower conduct, valuation movement and exit timing.
  2. Run Year 3 review before the policy endpoint approaches.
  3. Classify the file into full exit, partial exit, sale or final resolution.
  4. Protect capital through documentation, reporting and disciplined file management.
Appendix takeaway: exit risk is controlled by upfront exit underwriting, scheduled review, refinance-first execution, sale fallback and disciplined file management. The model should not rely on indefinite extension or property-growth hope.
