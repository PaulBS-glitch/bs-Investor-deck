Appendix 2 / Formula and worked example

Explain the exit formula and worked transaction economics.

This appendix shows how the BuySooner exit amount is calculated without monthly interest, monthly repayments or compounding.

01

Formula logic

Exit value equals the initial contribution plus a formula-based participation amount linked to contribution size, time outstanding and exit property value.

02

Worked example

A simple $1m / 80 / 10 / 10 scenario can show the contribution, senior mortgage, customer equity and exit amount.

03

Sensitivity

Examples can test contribution size, exit timing, pricing multiplier and property value at refinance or sale.

Core formula

Formula-based, not interest-based.

The formula should be shown as an appendix item so the main deck remains simple while investors can still inspect the mechanics.

Exit = ICC + (PV × r × T)
r = (1 / k) × (ICC / HV)
Appendix takeaway: the model is transparent because the exit amount is formula-led and can be sensitivity tested.
